### Game Description 
Connect Four is a fun two-player strategy game where players take turns dropping colored discs into a grid. The goal is to connect four discs of the same color horizontally, vertically, or diagonally before your opponent. The first player to connect four wins! You can restart the game or play again, and the scoreboard keeps track of each player's wins.
